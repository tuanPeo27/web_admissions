# Web Admissions

Portal tra cuu ket qua xet tuyen cho thi sinh (Spring MVC + Thymeleaf).

## Yeu cau
- Java 17
- Maven 3.9+
- MySQL 8.x

## Cau hinh
Cau hinh DB trong `src/main/resources/application.properties`.

## Chay ung dung
```bash
mvn spring-boot:run
```

## Duong dan
- `/login`: Dang nhap (CCCD + mat khau)
- `/ket-qua`: Ket qua theo tung nguyen vong
- `/tra-cuu/phuong-thuc`: Tra cuu diem theo phuong thuc
- `/tra-cuu/to-hop`: Tra cuu diem theo to hop mon
